# AI Chat UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give ADMIN/IT users a Flask-served chat page where they talk to the AI copilot and approve/apply its proposed changes inline, backed by a shared, persisted chat transcript.

**Architecture:** A new `network_copilot/chat/` backend module (model + service + routes) records every exchange through the existing `POST /api/ai/chat`, without modifying `ai/service.py`. A single HTML page, served directly by Flask, uses vendored Alpine.js (no build step, no CDN) to render three columns — devices, chat, pending changes — all driven by the existing JSON API.

**Tech Stack:** Flask (existing), SQLAlchemy (existing), Alpine.js 3.x (new, vendored as a static file), plain HTML/CSS/JS (no bundler, no Node.js).

**Spec:** `docs/superpowers/specs/2026-07-30-ai-chat-ui-design.md`

## Global Constraints

- No Node.js, no JS build step, no CDN script tags — Alpine.js is vendored into `static/vendor/alpine.min.js` and loaded from there.
- `ai/service.py` is not modified. All chat-history recording happens in `ai/routes.py` and the new `chat/` module.
- `GET /api/chat/messages` requires authentication only, no role restriction (VIEWER/OPERATOR can read, matching the existing "monitor" visibility level).
- `record_message` must never raise — a failure to persist chat history must never break the AI response the user is waiting for (same rule as `audit.service.record_event`).
- After Task 4, the full existing test suite (416 tests as of this plan) must still pass unmodified — this confirms the `ai/routes.py` edit did not regress anything.
- No JavaScript test framework is introduced. Frontend tasks are verified manually in a real browser using the Browser tool, per the project's existing rule that UI changes must be exercised in a browser before being reported complete.

```python
"""Shared team chat transcript with the AI copilot."""

from datetime import datetime, timezone

from ..extensions import db

CHAT_ROLES = ("user", "assistant", "system")


class ChatMessage(db.Model):
    __tablename__ = "chat_messages"

    id = db.Column(db.Integer, primary_key=True)
    user_id = db.Column(
        db.Integer, db.ForeignKey("users.id", ondelete="SET NULL"), index=True
    )
    username = db.Column(db.String(64))
    role = db.Column(db.String(16), nullable=False)
    content = db.Column(db.Text, nullable=False, default="")
    payload = db.Column(db.JSON)
    created_at = db.Column(
        db.DateTime,
        nullable=False,
        default=lambda: datetime.now(timezone.utc),
        index=True,
    )

    def to_dict(self) -> dict:
        return {
            "id": self.id,
            "user_id": self.user_id,
            "username": self.username,
            "role": self.role,
            "content": self.content,
            "payload": self.payload,
            "created_at": self.created_at.isoformat() if self.created_at else None,
        }

    def __repr__(self) -> str:  # pragma: no cover - debugging helper
        return f"<ChatMessage {self.role} #{self.id}>"
```

Create `backend/src/network_copilot/chat/service.py`:

```python
"""Shared team chat transcript with the AI copilot.

Every exchange through POST /api/ai/chat is recorded here, whether it
succeeded, was blocked by the policy engine, or failed upstream, so anyone
reopening the page sees exactly what happened, not just the calls that
returned 200.
"""

import logging

from ..extensions import db
from .model import ChatMessage

logger = logging.getLogger(__name__)


def record_message(
    user_id: int | None,
    username: str | None,
    role: str,
    content: str,
    payload: dict | None = None,
) -> ChatMessage | None:
    """Persist one chat message. Never raises: a failure to record history
    must not break the AI response the user is waiting for."""
    try:
        message = ChatMessage(
            user_id=user_id,
            username=username,
            role=role,
            content=content or "",
            payload=payload,
        )
        db.session.add(message)
        db.session.commit()
        return message
    except Exception:  # pragma: no cover - defensive, matches audit.service
        logger.exception("Failed to record chat message (role=%s)", role)
        try:
            db.session.rollback()
        except Exception:
            pass
        return None


def list_messages(limit: int = 200) -> list[ChatMessage]:
    return (
        db.session.query(ChatMessage)
        .order_by(ChatMessage.created_at.asc(), ChatMessage.id.asc())
        .limit(min(max(limit, 1), 500))
        .all()
    )
```

```python
from ..auth.service import current_user
from ..chat.service import record_message as record_chat_message
from ..errors import AppError, ValidationError
from ..extensions import limiter
```

Replace `backend/src/network_copilot/static/js/app.js`:

```js
document.addEventListener("alpine:init", () => {
  Alpine.data("app", () => ({
    // -- auth state --
    token: localStorage.getItem("nc_token") || null,
    currentUser: JSON.parse(localStorage.getItem("nc_user") || "null"),
    loginForm: { username: "", password: "" },
    loginError: "",

    init() {
      if (this.token) {
        this.authFetch("/api/auth/me")
          .then((user) => {
            this.currentUser = user;
            localStorage.setItem("nc_user", JSON.stringify(user));
            return this.startApp();
          })
          .catch(() => {
            /* authFetch already logged out on a 401 */
          });
      }
    },

    async authFetch(path, options = {}) {
      const headers = Object.assign(
        { "Content-Type": "application/json" },
        options.headers || {},
        this.token ? { Authorization: `Bearer ${this.token}` } : {}
      );
      const response = await fetch(path, { ...options, headers });
      if (response.status === 401) {
        this.logout();
        throw new Error("session_expired");
      }
      const data = await response.json().catch(() => ({}));
      if (!response.ok) {
        throw new Error(data.message || `Request failed (${response.status})`);
      }
      return data;
    },

    async login() {
      this.loginError = "";
      try {
        const data = await this.authFetch("/api/auth/login", {
          method: "POST",
          body: JSON.stringify(this.loginForm),
        });
        this.token = data.access_token;
        this.currentUser = data.user;
        localStorage.setItem("nc_token", this.token);
        localStorage.setItem("nc_user", JSON.stringify(this.currentUser));
        this.loginForm = { username: "", password: "" };
        await this.startApp();
      } catch (err) {
        this.loginError = err.message || "Đăng nhập thất bại.";
      }
    },

    logout() {
      this.token = null;
      this.currentUser = null;
      localStorage.removeItem("nc_token");
      localStorage.removeItem("nc_user");
    },

    // Filled in by Task 8 (devices), Task 9 (changes), Task 10 (chat).
    async startApp() {},
  }));
});
```

**The one bug this task must not introduce:** do not snapshot a change into a plain local variable via `x-data="{ change: changesById[id] }"` on the action card. That plain property is assigned once, when the card first renders, and will not update when `changesById[id]` is later replaced by `approveChange`/`applyChange` (which assign a *new* object to that key rather than mutating the existing one in place) — the card would then show stale status forever after the first click. Use a **getter** (`get change() { return changesById[id]; }`) instead: a getter body re-runs on every reactive read, so it always reflects the current entry in the map. This is why the markup below uses a getter.

Add the chat methods, after `cancelChange`:

```js
    _ingestMessage(message) {
      this.messages.push(message);
      const change = message.payload && message.payload.change;
      if (change && change.id != null && !(change.id in this.changesById)) {
        this.changesById[change.id] = change;
      }
    },

    _isScrolledToBottom() {
      const el = this.$refs.chatLog;
      if (!el) return true;
      return el.scrollHeight - el.scrollTop - el.clientHeight < 40;
    },

    _scrollToBottom() {
      const el = this.$refs.chatLog;
      if (el) el.scrollTop = el.scrollHeight;
    },

    async hydrateMessages() {
      const data = await this.authFetch("/api/chat/messages");
      for (const message of data.items) this._ingestMessage(message);
      this.$nextTick(() => this._scrollToBottom());
    },

    async pollMessages() {
      const wasAtBottom = this._isScrolledToBottom();
      const data = await this.authFetch("/api/chat/messages");
      const known = new Set(this.messages.map((m) => m.id));
      let appended = false;
      for (const message of data.items) {
        if (!known.has(message.id)) {
          this._ingestMessage(message);
          appended = true;
        }
      }
      if (appended && wasAtBottom) {
        this.$nextTick(() => this._scrollToBottom());
      }
    },

    async sendMessage() {
      const text = this.draftMessage.trim();
      if (!text || this.sending) return;
      this.draftMessage = "";
      this.sending = true;
      try {
        await this.authFetch("/api/ai/chat", {
          method: "POST",
          body: JSON.stringify({ message: text }),
        });
      } catch (err) {
        // The failure is already durably recorded server-side as a system
        // message; pollMessages() below fetches it immediately rather than
        // waiting for the next scheduled tick.
      } finally {
        await this.pollMessages();
        this.sending = false;
      }
    },
```
